# 北京亲子游安心预约助手

> 暑期带娃来北京玩，哪些景点要提前预约？提前几天？几点放票？儿童怎么买票？—— 一个页面全搞定。

## 这是什么

一个帮助家长规划北京热门景点预约的小工具。输入你的出行日期、天数、人数，勾选想去的景点，自动生成个性化的预约方案——包括放票倒计时、预约时间线、操作清单、儿童票指南等。

**无需注册，无需登录，打开即用。** 所有数据存在你本地浏览器里，刷新不丢。

## 在线使用

🔗 **[https://daka-agent.github.io/BookingAssistant/](https://daka-agent.github.io/BookingAssistant/)**

手机微信里直接打开链接就能用。

## 怎么用

1. **填写出行信息** — 到京日期、游玩天数、成人和儿童人数（及年龄）
2. **选择想去的景点** — 12 个北京热门预约景点可多选，每个带难度标签和放票时间
3. **自动生成预约方案** — 包含以下内容：
   - 📊 **状态看板** — 所有景点的预约状态一览，点击可标记"已约上"
   - ⏰ **实时倒计时** — 自动找最近的放票窗口，天/时/分/秒倒计时
   - 📅 **预约时间线** — 按日期排列所有放票时间点，标注优先级
   - 🃏 **策略卡片** — 每个景点的预约渠道、票价、儿童政策、闭馆日等
   - ✅ **操作清单** — 按放票日期分组，可勾选完成
   - 👶 **儿童票指南** — 根据输入的儿童年龄自动匹配免票/优惠政策
   - 🗓️ **日程推荐** — 自动排布游玩日程，标注闭馆日

## 技术栈

- 纯前端单页应用（单 HTML 文件，无后端）
- Vanilla JS + CSS Grid/Flexbox
- localStorage 持久化
- 暗黑科技风 UI，移动端适配（微信内置浏览器友好）
- 部署在 GitHub Pages

## 数据时效

- 景点放票规则、票价、儿童政策等信息整理于 2026 年 7 月
